# 📄 Before Exam

* **Correo 3 dias antes, con URL de proctoring con credenciales (15min antes)**
* **Comprobaciones antes del examen**
  * Compartir pantallas con extension "Janus WebRTC Screensharing"
  * Compartir webcam
  * 360º con webcam a la habitación (nada tecnologico cerca)
  * Enseñar DNI a la webcam (tener una foto/copia en el ordenador)
  * Correr script PS y enviar resultado
* **Cuando todo esta correcto**
  * Envían URL web de reporte flags y reset de maquinas (con descripción de cada maquina) (en Kali)
  * [Fichero VPN con tus credenciales](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide-Newly-Updated#exam-connection)

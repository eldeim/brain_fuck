# 📄 In Exam

* **Restricciones**
  * No se puede utilizar AI (chatGPT ...)
  * No se puede hacer spoofing
  * No se puede utilizar herramientas de pago (BurpSuite Pro ...)
  * No se puede utilizar herramientas de explotación auto (Sqlmap ...)
  * No se puede utilizar herramientas escaners masivas (Nessus, openVAS ...)
  * No puedes hablar con nadie (WhatsApp, Discord ...)
  * Solo se puede utilizar unas vez Metasploit (no se puede utilizar en el pivoting)
    * Si se utiliza, en el informe hay que expresarlo
* [**Recordar reportar todas las flags en el panel que dan**](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide-Newly-Updated#control-panel-submission)
